# 学习进度与已验证结果

日期：2026-10-12。当前检查点：第一阶段已完成；建议先阅读 `01-geometry-and-step.md` 并做其中的半径和偏心孔练习。下一阶段为边界标记与网格。

## 第一阶段实测

- 编译：G++ 13.3 / CMake 3.28，Debug，`-Wall -Wextra -Wpedantic`，无编译警告。
- API 与运行库：均为 Gmsh 4.12.1。
- 自动验收：`ctest --test-dir build --output-on-failure`，1 个集成套件通过；套件内部包含 6 个测试组和 13 个非法输入子案例。
- 几何：100 × 50 mm，孔半径 10 mm，孔心 (50,25) mm；1 个面、5 条曲线、2 个闭合环、0 个体、0 个网格节点、0 个网格单元。
- 面积：0.004685840734641022 m²。
- 总边界长度：0.3628318530717959 m。
- 导出前与导入后的面积和长度都与解析基准在本机 double 表示下相同；不据此宣称任意几何的精确性。
- STEP：文件声明毫米；内部及读回用米；测试独立核对文件坐标与声明单位。
- 代码审查补齐：实测孔位置验证、构造失败清理。
- 可视检查：预览坐标等比例、单位明确、圆孔位置正确，已修正图注与坐标标题重叠。
