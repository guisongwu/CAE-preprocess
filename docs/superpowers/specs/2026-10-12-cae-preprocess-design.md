# 二维带孔板 CAE 前处理与导热演示：已批准设计

用户于 2026-10-12 批准二维带孔板导热方案，并要求分阶段实施、讲清每一步的代码和原理。本次交付第一阶段；不重复请求已批准设计的确认。

## 全项目目标

通过 C++17 + Gmsh/OpenCASCADE + Eigen 展示参数化几何、STEP 往返、边界语义识别、孔边局部加密、网格质量、求解器适配与 P1 稳态导热有限元验证。网格生成算法归属于 Gmsh；项目自己的贡献是数据组织、验证、接口和可复现流程。

## 阶段划分

1. 几何与 STEP：建立矩形减圆盘的单面域，导出后清空模型重新导入，独立检查面积、总周长、两个闭合边界环、包围盒；生成 JSON 报告和几何示意图。
2. 边界与网格：识别 left/right/top/bottom/hole，孔边加密，输出网格与质量报告；检验边界覆盖与节点编号映射。
3. 有限元导热：常数导热率，左侧高温、右侧低温，其余边界绝热。实现 P1 三角形装配、Dirichlet 消元、稀疏求解和结果输出。
4. 数值验收：制造解收敛、残差、温度范围、反力形式的热流平衡；区分离散反力与直接梯度积分的精度。
5. 展示：中文教程、参数对比、图片、验证表及五分钟演示。

## 第一阶段的边界

所有工程参数和内部坐标统一为米；STEP 必须使用明确且可验证的单位策略。默认宽 0.1 m、高 0.05 m、孔半径 0.01 m，孔心在板中心。圆孔必须严格位于矩形内部，且与边界至少相距 1e-6 m；有限正参数才可接受，半径至少为 1e-6 m。支持孔偏置参数用于验证。

不在第一阶段生成网格、求解温度或启动图形窗口。图像只表达几何与单位，不用温度色彩暗示求解已经完成。几何生成与往返均必须通过数值检验，失败返回非零退出码。输出目录已存在时拒绝覆写。目录和失败残留必须由明确命令或用户选择处理。

## 接口与验收

命令：`geometry_demo --output <新目录> [--width W --height H --radius R --cx X --cy Y]`。

输出：`plate.step`、`geometry_report.json`，以及由报告生成的 `geometry_preview.png/svg`。报告记录软件版本、长度单位、参数、解析基准、导出前/导入后的实测几何量、误差与 PASS。

默认验收：单个二维面、零三维体、两个独立闭合边界环；面积和周长相对误差不超过 1e-8；包围盒坐标误差不超过 1e-6 m；每个环独立进行端点闭合与连通性检查，并核对实际孔边采样的位置和外矩形边界；环周长分别对应矩形外边界和圆孔。面 tag 和曲线 tag 可以改变。

测试至少覆盖默认参数、偏心孔、不同尺寸、非法半径、孔越界、非有限数、缺少参数值、输出已存在。可视化从实测报告读取参数，以等比例坐标表示；几何检验不依赖图片。
